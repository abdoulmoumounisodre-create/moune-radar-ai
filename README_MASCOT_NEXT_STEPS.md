La mascotte est maintenant intégrée visuellement dans l'application.

Étapes importantes :

1) Fournir l'image détourée
- Créez un PNG détouré (fond transparent) basé sur votre photo (head-and-shoulders). Nommer le fichier `mascot.png` et déposer dans le dossier `public/` du dépôt (racine) : `public/mascot.png`.
- Taille recommandée : 1000px hauteur maximum. Prévoir une version miniature 128x128 pour notifications `public/mascot-mini.png` (optionnelle).

2) Prévisualiser
- Après avoir ajouté `public/mascot.png`, lancez l'app localement : `npm run dev`.
- Le fichier sera automatiquement utilisé sur la page d'accueil (section hero), sur le badge flottant en bas à droite et dans le chat.

3) Respect de l'identité
- Vérifiez que vous avez l'autorisation de publier cette photo à des fins commerciales ou de marque.

4) Personnalisation (optionnelle)
- Si vous voulez une version stylisée (illustration vectorielle) à partir de la photo, fournissez des instructions et je préparerai des assets SVG/PNG stylisés.
