# MOUNERADAR AI

Plateforme pré-lancement — détection d'aubaines de vols (interface, UI, pages et placeholders d'intégration).

Slogan: "L'IA qui repère les vols à prix cassés."

Tech: Next.js (App Router), TypeScript, Tailwind CSS.

Important: aucune clé API ni intégration de données en production n'est incluse. Les fonctionnalités IA/Supabase/Stripe sont préparées mais inactives jusqu'à configuration.

Démarrage:

1. Copier .env.example -> .env.local et configurer SUPABASE_URL, SUPABASE_ANON_KEY, OPENAI_API_KEY, STRIPE_SECRET si vous souhaitez activer les services.
2. npm install
3. npm run dev
